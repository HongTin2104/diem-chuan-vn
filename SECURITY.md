# Security policy

This project holds public data and a small read-only web app; it stores no user data and no
credentials. Still, if you find a security problem (for example in the extractors or the app),
please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/HongTin2104/diem-chuan-vn/security/advisories/new)
or by email to hongtin2104@gmail.com. You should get a reply within a week.

Wrong values in the data are not security issues; please report those as ordinary issues with a
link to the official source.

Only the latest release is supported.
